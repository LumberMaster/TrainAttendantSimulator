# TrainAttendantSimulator
Как собрать

Открыть папку unity-project в Unity 6000.3.14f1
(модуль WebGL Build Support должен быть установлен).

1. File → Build Profiles → WebGL → Switch Platform.
2. Build → выбрать папку Builds.
3. Готово — файлы сборки появятся в Builds.
4. Загрузить билд сборки в папку статики файлов на сервере
